# OpenCode для офисных сотрудников — комплект установки

Комплект для установки ИИ-помощника OpenCode с доступом к DeepSeek через Plexus. Устанавливается сотрудникам силами администраторов (Виктор, Олег Сигутин) — от сотрудника не требуется ни Терминала, ни тестирования: после установки ему показывают примеры задач ([task_examples.md](task_examples.md)).

Комплект один на оба языка. Язык установщика, документации и промптов самого помощника выбирается ключом `--lang ru` или `--lang en`; без ключа установщик берёт язык системы macOS.

## Состав комплекта

| Пакет | Что ставит | Кому нужен |
|---|---|---|
| 1 — [OpenCode + Plexus](package1.md) | Приложение OpenCode Desktop, подключение DeepSeek через Plexus (ключ сотрудника), отключение агента build, основной агент office | Всем |
| 2 — [Браузерный агент](package2.md) | Субагент @browser: управление сайтами в Chrome, сбор контактов и документов | Кому нужны задачи «с сайтов» |
| 3 — [OfficeCLI](package3.md) | Создание и правка документов Word и таблиц Excel словами в чате | Кому нужны документы Word/Excel |

Пакеты независимы — ставьте любую комбинацию ключом `--packages`. Пакет 1 должен быть первым: пакеты 2 и 3 только дополняют созданный им конфиг.

## Установка одному сотруднику (20–30 минут)

1. Взять ключ сотрудника в Vaultwarden (запись с ключом Plexus, формат `sk-air-…`). Если записи нет — создать ключ в Plexus и записать в Vaultwarden.
2. Скопировать папку комплекта на компьютер сотрудника (например, `~/Downloads/OpenCode_Kit`).
3. **Дважды щёлкнуть `Install.command`** в папке комплекта. Скрипт спросит три вещи — язык, ключ Plexus сотрудника и какие пакеты ставить (Enter — все три), покажет сводку и дальше сделает всё сам. Ни знания Терминала, ни пароля администратора не нужно: всё ставится только для текущего пользователя.

   Для автоматической установки движок можно вызвать напрямую из Терминала (Spotlight → наберите `Terminal` → Enter):

   ```bash
cd ~/Downloads/OpenCode_Kit/scripts
   ./install.sh --plexus-key "sk-air-XXXX"
   ./install.sh --plexus-key "sk-air-XXXX" --lang ru --packages 1,3
   ```

4. Запустить OpenCode Desktop и **показать сотруднику** 2–3 примера из [task_examples.md](task_examples.md) — чтобы он сразу увидел, что теперь можно делать (например: «создай письмо в Word» и «собери контакты с сайта в Excel»).
5. Для пакета 2: объяснить, что для задач «с сайтов» ничего запускать вручную не нужно — агент сам открывает Chrome; файл «Браузер для OpenCode» на рабочем столе нужен только как запасной вариант.

### Параметры установщика

| Параметр | Значение |
|---|---|
| `--plexus-key "sk-air-XXXX"` | Ключ сотрудника. Обязателен для пакета 1. |
| `--lang ru` \| `en` | Язык документации, промптов агента и вывода в консоль. По умолчанию — язык системы macOS. |
| `--packages 1,2,3` | Какие пакеты ставить. По умолчанию — все три. |
| `--skip-app-install` | Не скачивать и не устанавливать приложение OpenCode Desktop. |
| `--keep-build` | Не отключать агента build (для опытных сотрудников). |
| `--no-shortcut` | Не класть запуск браузера на рабочий стол. |
| `--skip-checks` | Пропустить установку `uv` и проверку MCP-серверов (установка без интернета). |
| `--target-dir`, `--data-dir` | Переопределить папки конфигурации и данных OpenCode. |


## Удаление

**Дважды щёлкните `Uninstall.command`** в папке комплекта. Скрипт спросит, какие пакеты удалять, и переспросит перед тем, как что-то трогать: Enter на подтверждении отменяет операцию, удаление происходит только при явном ответе «y».

Либо из Терминала:

```bash
cd ~/Downloads/OpenCode_Kit/scripts
./uninstall.sh                     # все три пакета
./uninstall.sh --packages 2         # только браузерный агент
./uninstall.sh --packages 2 --purge  # ...и вместе с отладочным профилем Chrome
```

Деинсталлятор убирает ровно то, что добавил установщик: свои ключи в `opencode.json`, свои размеченные блоки в `AGENTS.md`, файлы агентов, `start-browser.command`, `ensure-browser.command`, файл запуска на рабочем столе и ключ Plexus в `auth.json`. Настройки, которые сотрудник добавил сам, остаются на месте, а конфиг предварительно сохраняется в бэкап.

Не удаляются: документы сотрудника, профиль Chrome с логинами (для удаления — `--purge`), бэкапы конфига и само приложение OpenCode Desktop.

## Важное

- Ничего не перезаписывается вслепую. Перед каждым изменением `opencode.json` сохраняется в бэкап (`opencode.json.backup-…`), при переустановке сохраняются уже настроенные MCP-серверы и права, повторный запуск установщика безопасен — он ничего не задваивает.
- Опытным сотрудникам build можно не отключать: ключ `--keep-build` (или включить позже — см. раздел 5 в [package1.md](package1.md)).
- Первая установка: Лапаева — отключить build, доступ через Plexus, OfficeCLI.

## Структура комплекта

```
Install.command     двойной щелчок — установка
Uninstall.command   двойной щелчок — удаление
scripts/        install.sh, uninstall.sh (движки для автоматизации),
                interactive.sh (вопросы, стоящие за двумя .command),
                lib/common.sh + lib/kit.py
                и i18n/<язык>.json (все сообщения консоли)
docs/<язык>/    эта документация
package1_opencode_plexus/   opencode.json и агент office по языкам
package2_browser_agent/     MCP-сервер chrome-devtools, start-browser.command,
                            ensure-browser.command,
                            субагент @browser по языкам
package3_officecli/         MCP-серверы Word/Excel и проверка их запуска
```

Файлы, не зависящие от языка (`opencode.json`, фрагменты MCP, скрипты `*-browser.command`), существуют в одном экземпляре. По языкам дублируется только текст — в папках `locales/<язык>/` и `docs/<язык>/`. Чтобы добавить язык, добавьте `scripts/i18n/<язык>.json` и соответствующие папки `locales/<язык>/` и `docs/<язык>/` — непереведённые сообщения автоматически возьмутся из английского.
