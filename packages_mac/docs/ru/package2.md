# Пакет 2 — браузерный агент

Установка субагента @browser: OpenCode управляет настоящим браузером Google Chrome (открывает страницы, кликает, заполняет формы, собирает контакты и документы с сайтов).

**1. Требования**

- Установлен пакет 1 (есть папка `~/.config/opencode\` с файлом `opencode.json`).
- Установлен Google Chrome.
- Установлен Node.js LTS (https://nodejs.org) — нужен для запуска MCP-сервера через npx.

**2. Установка (автоматически)**

Откройте Терминал (Spotlight → наберите `Terminal` → Enter) и выполните:

```bash
cd ~/Downloads/OpenCode_Kit/scripts
./install.sh --packages 2
```

Скрипт ничего не перезаписывает — он добавляет в существующий конфиг:

- MCP-сервер `chrome-devtools` (подключается к Chrome на порту 9222);
- запрет браузерных инструментов для всех агентов, кроме @browser (`"chrome-devtools_*": "deny"`);
- субагента `agents/browser.md` (в нём нет строки `model` — агент наследует модель основного агента);
- правила делегирования веб-задач в `AGENTS.md`, размеченные маркерами, чтобы их можно было аккуратно убрать;
- скрипт `ensure-browser.command` (агент @browser сам запускает его, чтобы поднять Chrome), скрипт `start-browser.command` и ярлык «Браузер для OpenCode» на рабочем столе.

Перед изменением `opencode.json` создаётся бэкап (`opencode.json.backup-…`). Ключ `--no-shortcut` отключает создание ярлыка.

**3. Как пользоваться**

1. Вручную запускать ничего не нужно: перед первым действием в браузере агент @browser сам выполняет `ensure-browser.command`, и тот открывает Chrome с отдельным профилем, если он ещё не запущен. Ярлык «Браузер для OpenCode» на рабочем столе делает то же самое вручную — если хочется открыть браузер заранее.
2. В чате OpenCode просто опишите задачу обычными словами, например: «Собери контакты с сайта https://… в таблицу», «Найди на сайте условия поставки», «Скачай прайс-лист и сведи цены в Excel».
3. Основной агент сам передаст задачу субагенту @browser; работу агента видно в окне Chrome.
4. Если агент отвечает «Chrome not found» — установите Google Chrome. Если он отвечает «Could not connect to the browser» даже после повторной попытки — запустите ярлык «Браузер для OpenCode» вручную и повторите запрос.

**4. Что умеет @browser**

- Навигация: открывать/закрывать/переключать вкладки, переходить по URL, ждать загрузки (`navigate_page`, `wait_for`, `list_pages`, `select_page`…).
- Действия на странице: клики, заполнение форм, ввод текста, клавиши, наведение (`click`, `fill`, `fill_form`, `type_text`…).
- Чтение страницы: текстовое дерево страницы (`take_snapshot`) — основной способ «видеть», плюс скриншоты по запросу.
- Извлечение данных: выполнение JavaScript на странице (`evaluate_script`).
- Отладка: ошибки консоли, сетевые запросы, performance-трейсы.

Безопасность: агент работает только в вашем браузере с вашими логинами; разрушительные действия (отправка, удаление, заказы) — только после явного подтверждения; пароли не вводит без прямого указания.

**5. Отдельный профиль Chrome**

`ensure-browser.command` сначала опрашивает `http://127.0.0.1:9222/json/version`; если оттуда приходит ответ, он сразу завершается и ничего не запускает. Иначе он запускает Chrome с ключом `--remote-debugging-port=9222` и собственным `user-data-dir` (`~/.config/opencode\chrome-debug-profile`). Отдельный профиль обязателен: современный Chrome отказывается открывать отладочный порт на обычном профиле. Логины и куки в этом профиле сохраняются между запусками.

**6. Удаление**

```bash
./uninstall.sh --packages 2          # профиль Chrome с логинами сохраняется
./uninstall.sh --packages 2 --purge   # профиль тоже удаляется
```

Убирает MCP-сервер, правило прав, `agents/browser.md`, `start-browser.command`, `ensure-browser.command`, файл запуска на рабочем столе и блок веб-задач из `AGENTS.md`.
