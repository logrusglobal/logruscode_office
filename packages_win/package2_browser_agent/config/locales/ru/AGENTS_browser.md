# Правила работы с веб-сайтами

- Задачи, связанные с работой на веб-сайтах в настоящем браузере (открытие страниц, клики, заполнение форм, сбор контактов и документов, проверка консоли/сети), должны делегироваться субагенту `@browser` через инструмент Task. Не пытайтесь автоматизировать браузер командами bash/curl/webfetch, когда нужно реальное взаимодействие с сайтом.
- Запускать браузер самостоятельно не нужно, и просить об этом пользователя тоже не нужно. Агент `@browser` сам выполняет `ensure-browser.cmd` перед первым действием в браузере: если отладочный Chrome уже запущен — ничего не меняется, если нет — он запускается и агент дожидается готовности. Ярлык «Браузер для OpenCode» на рабочем столе (он запускает `%USERPROFILE%\.config\opencode\start-browser.cmd`) остаётся ручным запасным вариантом — упоминайте его, только если агент браузера сообщил, что не смог запустить Chrome.
- Агент `@browser` работает через MCP-сервер `chrome-devtools`, подключённый к Chrome на отладочном порту 9222.
- Агенту `@browser` модель задана явно строкой `model` в его файле агента; её пишет установщик из поля `model` в `opencode.json`. Субагент без строки `model` НЕ наследует модель вызывающего агента: OpenCode берёт свою модель по умолчанию, попадает на бесплатный тариф и падает с ошибкой «OpenCode's free tier can only be used from within OpenCode». Если меняете модель в `opencode.json`, переустановите пакет 2, чтобы они не расходились.
