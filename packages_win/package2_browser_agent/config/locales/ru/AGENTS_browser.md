# Правила работы с веб-сайтами

- Задачи, связанные с работой на веб-сайтах в настоящем браузере (открытие страниц, клики, заполнение форм, сбор контактов и документов, проверка консоли/сети), должны делегироваться субагенту `@browser` через инструмент Task. Не пытайтесь автоматизировать браузер командами bash/curl/webfetch, когда нужно реальное взаимодействие с сайтом.
- Перед делегированием убедитесь, что Chrome с отладочным портом запущен (ярлык «Браузер для OpenCode» на рабочем столе или файл `%USERPROFILE%\.config\opencode\start-browser.cmd`). Если агент браузера сообщает об ошибке соединения, скажите пользователю запустить этот ярлык/файл и повторить запрос.
- Агент `@browser` работает через MCP-сервер `chrome-devtools`, подключённый к отдельно запущенному пользователем Chrome на порту 9222.
- Агент `@browser` наследует модель основного агента (в его файле `agents\browser.md` строка `model` не задана — так и должно быть). С Plexus это модель `lgplexus/deepseek-deepseek-v4-pro`.
