# OpenCode — OfficeCLI

OfficeCLI — это два локальных MCP-сервера (office-word и office-excel), которые дают OpenCode возможность создавать, читать и редактировать документы Word (.docx) и таблицы Excel (.xlsx) напрямую, без установленного MS Office и без написания программ.

## Installing OfficeCLI

**1. Требования**

- Установлен пакет «OpenCode + Plexus» (есть файл `%USERPROFILE%\.config\opencode\opencode.json`).
- Интернет для первого запуска (серверы скачивают свои пакеты один раз).

**2. Установка (автоматически)**

Откройте PowerShell (Пуск → наберите `powershell` → Enter) и выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
cd "D:\OpenCode_Kit\Пакет_3_OfficeCLI"
.\install_officecli.ps1
```

Скрипт ничего не перезаписывает — он добавляет в существующий конфиг MCP-серверы `office-word` и `office-excel` (перед изменением создаётся бэкап `opencode.json.backup-…`), ставит менеджер пакетов `uv`, если его нет, и проверяет запуск серверов.

Успешная проверка выглядит так:

```
office-word: HANDSHAKE OK
office-excel: HANDSHAKE OK
```

**3. Как пользоваться**

Полностью закройте и заново откройте OpenCode Desktop. Дальше просто пишите задачи обычными словами:

- «Создай письмо-подтверждение для клиента: заголовок, обращение, основной текст и таблица с реквизитами».
- «Посчитай сумму в столбце B файла budget.xlsx и выведи итог».
- «Прочитай договор.docx и перечисли все сроки в таблицу».
- «Собери данные из нескольких файлов Excel в одну сводную таблицу».

Агент сам вызовет инструменты `office-word_*` (Word) и `office-excel_*` (Excel). Первое создание файла после установки может занять до минуты — сервер скачивает пакеты, дальше быстрее.

**4. Ограничения**

- Файлы с макросами VBA (.docm/.xlsm) и сложным оформлением после автоматической правки обязательно открывайте в Word/Excel и проверяйте внешний вид.
- Презентации PowerPoint в этот пакет не входят.

**5. Примеры задач** — см. файл `Примеры_задач.md` в корне комплекта (разделы «Excel» и «Word»).
