# OpenCode для офисных сотрудников: комплект из трёх пакетов

Комплект для установки ИИ-помощника OpenCode с доступом к DeepSeek через Plexus. Устанавливается сотрудникам силами администраторов (Виктор, Олег Сигутин) — от сотрудника не требуется ни PowerShell, ни тестирования: после установки ему показывают примеры задач (файл `Примеры_задач.md`).

## Состав комплекта

| Пакет | Что ставит | Кому нужен |
|---|---|---|
| `Пакет_1_OpenCode_и_Plexus` | Приложение OpenCode Desktop, подключение DeepSeek через Plexus (ключ сотрудника), отключение агента build, основной агент office | Всем |
| `Пакет_2_Браузерный_агент` | Субагент @browser: управление сайтами в Chrome, сбор контактов и документов | Кому нужны задачи «с сайтов» |
| `Пакет_3_OfficeCLI` | Создание/правка документов Word и таблиц Excel словами в чате | Кому нужны документы Word/Excel |

Пакеты независимы: можно ставить любую комбинацию (например, только 1+3, без браузера, или только 1+2). Скрипты установки ничего не перезаписывают — они добавляют свои настройки в существующий конфиг и создают бэкапы.

## Порядок установки одному сотруднику (20–30 минут)

1. Взять ключ сотрудника в Vaultwarden (запись с ключом Plexus, формат `sk-air-…`). Если записи нет — создать ключ в Plexus и записать в Vaultwarden.
2. Скопировать папку комплекта на компьютер сотрудника (например, `D:\OpenCode_Kit`).
3. Установить пакет 1:

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   cd "D:\OpenCode_Kit\Пакет_1_OpenCode_и_Plexus"
   .\install_opencode.ps1 -PlexusKey "sk-air-Wh2AvCAtu2owl9GUKrGPtP4G0JHQSm8I"
   ```

4. По необходимости — пакет 2:

   ```powershell
   cd "D:\OpenCode_Kit\Пакет_2_Браузерный_агент"
   .\install_browser_agent.ps1
   ```

5. По необходимости — пакет 3:

   ```powershell
   cd "D:\OpenCode_Kit\Пакет_3_OfficeCLI"
   .\install_officecli.ps1
   ```

6. Запустить OpenCode Desktop и **показать сотруднику** 2–3 примера из `Примеры_задач.md` — чтобы он сразу увидел, что теперь можно делать (например: «создай письмо в Word» и «собери контакты с сайта в Excel»).
7. Для пакета 2: объяснить, что перед задачами «с сайтов» нужно запускать ярлык «Браузер для OpenCode» (создаётся на рабочем столе автоматически).
